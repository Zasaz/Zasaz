### 🎓 Research

**[cpp-llm-context-study](https://github.com/Zasaz/cpp-llm-context-study)**: Master's thesis, University of Vienna. How much project context should an LLM coding assistant actually see? It benchmarks context-selection strategies for C++ development, from whole-project dumps to structural context maps, on efficiency and accuracy. It includes the evaluation harness, corpus and results.
